Documentation

Add HumanVerification to your website.

1. Create a site

Open the dashboard and enter your website and Discord webhook.

2. Add the script 

<script
  src="https://YOUR-BACKEND-DOMAIN.com/verify.js?site=YOUR_SITE_KEY">
</script>

3. Done

The verification script runs when the visitor opens your website.
